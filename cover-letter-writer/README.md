# Cover Letter Writer

## Input

A current resume, job description, and any confirmed motivation or relevant story.

## Output

A concise letter, or a targeted question when key evidence is missing.

## Example

```text
Use cover-letter-writer with my resume and this job description. Keep it under 250 words and ask me for missing details; do not invent them.
```

## Setup and limits

Copy this folder to your agent's skill directory. No invented experience. Private story banks stay outside this repository.
