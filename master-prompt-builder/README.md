# Master Prompt Builder

## Input

A software idea, notes, or an existing PRD. Include known constraints.

## Output

Clarification questions, then requirements and a project constitution.

## Example

```text
Use master-prompt-builder. I need an invite-only book club reading list. Members can add books; only moderators can remove them. Help me clarify the remaining requirements.
```

## Setup and limits

Copy this folder to your agent's skill directory. Planning only; unresolved consequential decisions remain visible.
