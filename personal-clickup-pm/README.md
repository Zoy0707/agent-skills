# Personal ClickUp PM

## Input

An explicitly selected personal Space and a planning or review request.

## Output

A prioritized review or verified task changes within the requested scope.

## Example

```text
Use personal-clickup-pm to review Space [SPACE ID] and identify my three most important next actions. Make no changes.
```

## Setup and limits

Copy this folder to your agent's skill directory. Requires a connected ClickUp integration for live data; does not include scheduled monitoring.
