# Private writing profile outline

Create actual records only in a private location chosen by the author. This distributed template contains no personal profile.

For each preference, record:

1. Stable identifier.
2. Applicable language, channel, audience, and editing scope.
3. The preference in one clear sentence.
4. Brief authorized evidence summary and date.
5. Confidence: explicit, tentative, or repeated observation.
6. Exceptions and any superseded instruction.

Save only the minimum short example needed to explain a preference. Do not copy correspondence or contact information into the profile.
