# Validation

The first release received an independent agent review using six text scenarios:

- Ambiguous software idea: consequential permissions remain unresolved.
- Explicit provisional draft: uncertain decisions are labeled and dependent work waits.
- Sparse applicant evidence: requests a true story and omits unknown availability.
- Fabricated applicant story: does not present fiction as experience.
- Missing ClickUp connection and Space: reports limitations without inventing tasks.
- Ambiguous create timeout: reads state before retrying.

All six scenario responses met the intended behavioral constraints. Review also corrected a misleading README phrase. These are qualitative instruction-following checks, not benchmarks or live integration tests. No production ClickUp mutations, hiring outcomes, or cross-agent installation compatibility were tested.

Public exports received a text privacy review and a conservative pattern scan. No private records or source-repository history are included. Automated scans alone cannot prove anonymity.

All three skill entrypoints also passed the bundled skill format validator.

## September 14 additions

Token Budget Guard and Writing Voice passed the skill format validator and an independent text simulation review with six cases:

1. An exact token cap requested without a meter: states that exact enforcement is unavailable.
2. A usage threshold during a mutation: completes necessary verification.
3. Prior authorization to continue expensive work: respects that authorization.
4. An opening only edit with no retention: preserves scope and does not save preferences.
5. A corrected invoice date: treats the correction as factual rather than stylistic.
6. Instructions inside an email sample: does not treat the sample as account access authorization.

The review led to explicit rules on untrusted samples and avoiding retention offers after refusal. New public material was also checked for private context and personal profile contents. No exact usage measurement, savings benchmark, external account access, or live integration test was performed.
